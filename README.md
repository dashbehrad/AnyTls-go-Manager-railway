# AnyTLS Manager Panel (بهینه‌شده برای سرویس Railway)

> **پنل ساخته شده توسط aminiyt**

پنل مدیریت وب و خودکارسازی پروتکل **AnyTLS** مبتنی بر سورس رسمی [anytls/anytls-go](https://github.com/anytls/anytls-go)، با بهینه‌سازی ۱۰۰٪ برای دپلوی و اجرا روی کانتینرهای ابری **Railway** و قابلیت ساخت کانفیگ به کمک **TCP Proxy**.

---

## 🌟 ویژگی جدید: تنظیمات فوق‌العاده راحت و خودکار (Zero-Config)

برای دپلوی در Railway، **تنها ۲ متغیر** نیاز است:
1. `USERNAME` (یا `ADMIN_USERNAME`)
2. `PASSWORD` (یا `ADMIN_PASSWORD`)

**بقیه همه چیز به صورت ۱۰۰٪ خودکار تنظیم می‌شود:**
- ✅ **پورت وب پنل:** توسط Railway به طور خودکار تعیین و به دامنه وصل می‌شود.
- ✅ **هسته سرور AnyTLS:** باینری متناسب با سیستم شما خودکار دانلود و راه‌اندازی می‌شود.
- ✅ **پورت داخلی AnyTLS:** به صورت خودکار روی `8080` قرار می‌گیرد.
- ✅ **اتصال TCP Proxy:** با یک کلیک در بخش Networking ریلوی، دامنه و پورت خودکار شناسایی و در لینک کانفیگ اعمال می‌شود.
- ✅ **دامین SNI:** خودکار با `cloudflare.com` شبیه‌سازی می‌شود.

---

## 🌟 امکانات پنل (Features)

- 🚀 **بهینه‌سازی کامل برای کانتینر ریلوی (Railway Optimized):** پیکربندی شده با `Dockerfile` چندلایه‌ای، فایل‌های `railway.json` و `nixpacks.toml` برای بیلد سریع و بدون خطای کانتینر.
- 🌐 **پشتیبانی کامل از TCP Proxyینگ Railway:** به دلیل ماهیت کانتینرهای ابری، اتصال AnyTLS از طریق پروکسی لایه ۴ (TCP Proxy) هدایت می‌شود تا کلاینت‌هایی مانند **NekoBox** به راحتی به پورت AnyTLS متصل شوند.
- 🔑 **احراز هویت پایدار ادمین:** قابلیت تنظیم نام کاربری و پسوورد از طریق Variables در داشبورد Railway، بدون نگرانی از ریست شدن اطلاعات هنگام دپلوی مجدد (Ephemeral Storage).
- ⚙️ **دانلود و راه‌اندازی هوشمند باینری AnyTLS:** سیستم در صورت نبود فایل اجرایی `anytls-server` در کانتینر، باینری متناسب با معماری سرور (amd64 یا arm64) را به صورت خودکار دریافت کرده و پروسه‌ها را بالا می‌آورد.
- ⚡ **تست زنده اتصال TCP Proxy:** دارای ابزار داخلی تست پینگ و محاسبه تأخیر (Latency ms) به هاست و پورت TCP Proxy ریلوی.
- 📱 **تولید خروجی برای تمام کلاینت‌ها:**
  - لینک استاندارد `anytls://`
  - کد QR برای اسکن در گوشی
  - کانفیگ سفارشی برای **NekoBox** (اندروید و ویندوز)
  - کانفیگ استاندارد JSON برای هسته **Sing-box**
  - کانفیگ YAML برای **Clash Meta / Mihomo**
- 📊 **مانیتورینگ سیستم:** نمایش لحظه‌ای میزان مصرف RAM، CPU، آپتایم، وضعیت پروسه‌ها و لاگ‌های زنده.
- 🐧 **پشتیبانی همزمان از سرور لینوکس Ubuntu:** علاوه بر Railway، قابلیت نصب تک‌کلیکه با اسکریپت `install.sh` یا فایل ZIP روی سرور شخصی اوبونتو فراهم است.

## 🚀 راهنمای سریع راه‌اندازی در Railway (فقط ۳ مرحله ساده)

### گام اول: ساخت پروژه در Railway
1. وارد سایت [railway.com](https://railway.com) شوید.
2. روی دکمه **New Project** کلیک کنید.
3. گزینه **Deploy from GitHub repo** را زده و این ریپازیتوری را انتخاب نمایید.

### گام دوم: وارد کردن نام کاربری و پسوورد (فقط همین ۲ تا!)
1. در داشبورد پروژه روی سرویس کلیک کرده و وارد تب **Variables** شوید.
2. دو متغیر زیر را اضافه کنید:

| نام متغیر (Variable) | مقدار نمونه | توضیحات |
|----------------------|-------------|---------|
| `USERNAME` | `admin` | نام کاربری ورود به پنل |
| `PASSWORD` | `یک_رمز_قوی_و_دلخواه` | رمز عبور ادمین پنل |

*(همچنین می‌توانید از نام‌های `ADMIN_USERNAME` و `ADMIN_PASSWORD` نیز استفاده کنید)*.

### گام سوم: افزودن TCP Proxy در ریلوی
به دلیل این‌که ارتباط AnyTLS ترافیک خام TCP است:
1. در صفحه سرویس ریلوی، به تب **Settings** بروید.
2. به بخش **Networking** اسکرول کرده و در قسمت **TCP Proxying**، روی دکمه **Add TCP Proxy** کلیک کنید.
3. مقدار **Internal Port** را عدد `8080` بگذارید.
4. تمام! ریلوی به طور خودکار اطلاعات هاست و پورت TCP Proxy را ایجاد می‌کند و پنل آن را خودکار در کانفیگ‌های شما اعمال می‌نماید.

## 📱 آموزش وارد کردن کانفیگ در کلاینت‌ها

### در NekoBox (اندروید و ویندوز):
1. وارد پنل خود شوید، روی دکمه **QR Code / Link** کلیک کنید و لینک را کپی نمایید:
   ```text
   anytls://PASSWORD@junction.proxy.rlwy.net:12345?sni=cloudflare.com&insecure=1#Railway-AnyTLS
   ```
2. نرم‌افزار **NekoBox** را باز کنید، روی آیکون **+** بزنید و **Import from Clipboard** را انتخاب نمایید.
3. متصل شوید!

### در Sing-Box:
در مودال پنل، روی زبانه **Sing-box JSON** کلیک کنید تا بلوک خروجی استاندارد آماده را کپی کنید:
```json
{
  "tag": "anytls-out",
  "type": "anytls",
  "server": "junction.proxy.rlwy.net",
  "server_port": 12345,
  "password": "YOUR_PASSWORD",
  "tls": {
    "enabled": true,
    "server_name": "cloudflare.com",
    "insecure": true
  }
}
```

## 📋 جدول متغیرها (خلاصه)

| متغیر | الزامی؟ | مقدار پیش‌فرض | توضیحات |
|-------|---------|---------------|---------|
| `USERNAME` یا `ADMIN_USERNAME` | ✅ **بله** | `admin` | نام کاربری ادمین پنل |
| `PASSWORD` یا `ADMIN_PASSWORD` | ✅ **بله** | `admin123` | رمز عبور ورود به پنل |
| `PORT` | ❌ خیر (خودکار) | `3000` | پورت وب پنل (ریلوی خودکار ست می‌کند) |
| `ANYTLS_PORT` | ❌ خیر (خودکار) | `8080` | پورت داخلی سرور AnyTLS |
| `SNI_DEFAULT` | ❌ خیر (خودکار) | `cloudflare.com` | دامنه استتار TLS |
| `RAILWAY_TCP_PROXY_DOMAIN` | ❌ خیر (خودکار) | شناسایی از ریلوی | دامنه اختصاصی پروکسی ریلوی |
| `RAILWAY_TCP_PROXY_PORT` | ❌ خیر (خودکار) | شناسایی از ریلوی | پورت اختصاصی پروکسی ریلوی |
